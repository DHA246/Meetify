# Meetify 🎥

Meetify is a full-stack video communication platform built for seamless online meetings and collaboration. It enables users to create rooms, join meetings, and communicate in real-time with low-latency peer-to-peer connections.

## 🚀 Features

- User Authentication (Login / Signup)
- Create & Join Meeting Rooms
- Real-time Video & Audio Communication
- Room Management
- Meeting History Tracking
- Real-time Signaling
- Secure Password Handling
- Responsive UI

## 🛠 Tech Stack

### Frontend
- React.js
- Material UI
- CSS

### Backend
- Node.js
- Express.js

### Real-time Communication
- WebRTC
- Socket.io

### Database
- MongoDB

### Authentication & Security
- Bcrypt
